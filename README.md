# Dedhed

Proposal for a live concert library with on-demand sets and a shared radio
station, beginning with the Grateful Dead
collection at Internet Archive and reusing suitable tools from
[Arkhiv](https://git.subcult.tv/subculture-collective/arkhiv).

This workspace contains a first milestone proposal. It does not yet contain a
player, station service, acquired audio, or deployment.

The first version supports two listening modes: browse a concert and play a set
or full show on demand, or click **Tune in** to join the shared station at its
current position. Both show the concert date, venue, track, and recording credits.
On-demand controls affect only that listener; the station keeps its own timeline.

See [the first milestone](docs/plans/0001-grateful-dead-radio.md) for reuse
boundaries, source evidence, playback choices, and acceptance criteria.
